# herdr-kanban

칸반 보드를 터미널에서 보고 상태를 바꾸는 [Herdr](https://herdr.dev) 플러그인입니다.

`kanban.yooit.kr` 의 일감을 pane 안에 그리고, 키보드와 마우스로 돌아다니며 카드를 다른 칸으로 옮깁니다. 다른 창에서 일감이 바뀌면 화면이 따라 갱신됩니다.

## 할 수 있는 일

- 프로젝트의 칸반 보드 표시 (칸별 카드, 우선순위, 마감일, 하위 일감 진행도)
- 선택한 일감의 상세 패널 (설명, 담당자, 하위 일감, 댓글 읽기)
- 키보드 탐색 (카드 위아래, 칸 좌우, 칸의 처음과 끝)
- 제목 검색과 우선순위 필터
- 프로젝트 전환 (마지막 선택을 기억합니다)
- 실시간 갱신 (SSE, 끊기면 주기 갱신으로 내려갑니다)
- 마우스 클릭·더블클릭·휠 스크롤·드래그 앤 드롭
- 상태 변경 (`Space`, `H`/`L`, 드래그)

## 할 수 없는 일

**이 플러그인은 조회와 상태 변경만 합니다.** 다음은 칸반 웹이나 MCP 서버에서 하십시오.

- 일감 생성·수정·삭제
- 하위 일감 생성
- 댓글 작성

터미널에서 긴 글을 쓰기보다, 보드를 훑고 카드를 옮기는 일에 집중하도록 범위를 좁혔습니다.

## 설치

```bash
herdr plugin install world-goes-to-hell/ysk-kanban/herdr-plugin
```

로컬 저장소에서 바로 쓰려면 다음처럼 연결합니다.

```bash
cd herdr-plugin
npm install
npm run build
herdr plugin link .
```

Node.js 22 이상이 필요합니다. 네이티브 모듈은 쓰지 않으므로 컴파일 단계가 없습니다.

## 최초 설정

처음 열면 설정 화면이 뜹니다. 서버 주소와 API Key 를 넣고 `Enter` 를 누르면 저장되고 바로 보드로 넘어갑니다.

| 항목 | 설명 |
|------|------|
| 서버 주소 | 기본값 `https://kanban.yooit.kr` |
| API Key | `ak_` 로 시작하는 문자열 |

**API Key 는 칸반 웹의 프로젝트 설정에서 발급합니다.** 설정 파일 위치는 다음으로 확인할 수 있습니다.

```bash
herdr plugin config-dir herdr-kanban
```

## 여는 방법

```bash
herdr plugin pane open --plugin herdr-kanban --entrypoint board
```

Linux 와 macOS 에서는 `--entrypoint board-unix` 를 씁니다.

### 단축키로 열기

Herdr 의 `config.toml` 에 다음을 더하면 키 하나로 보드를 열 수 있습니다.

```toml
[[keys.command]]
key = "ctrl+shift+k"
command = "herdr-kanban.open-board"
```

Windows 에서는 액션 id 가 `herdr-kanban.open-board-windows` 입니다. 액션 id 는 플랫폼이 달라도 전역에서 유일해야 해서 Windows 쪽에만 접미사가 붙어 있습니다.

## 키맵

### 이동

| 키 | 동작 |
|----|------|
| `j` / `k` | 카드 위아래 |
| `h` / `l` | 칸 좌우 |
| `g` / `G` | 칸의 처음 / 끝 |
| `Tab` | 보드와 상세 전환 |

### 보기

| 키 | 동작 |
|----|------|
| `Enter` | 상세 열기 |
| `/` | 제목 검색 (치는 동안 바로 걸러집니다) |
| `f` | 우선순위 필터 |
| `p` | 프로젝트 전환 |
| `r` | 새로고침 |

### 상태

| 키 | 동작 |
|----|------|
| `Space` | 칸 목록에서 골라 상태 변경 |
| `H` / `L` | 옆 칸으로 이동 |

완료 칸으로 옮길 때 끝나지 않은 하위 일감이 있으면 확인을 묻습니다.

### 기타

| 키 | 동작 |
|----|------|
| `m` | 마우스 켜기·끄기 |
| `?` | 도움말 |
| `Esc` | 열린 팝업 닫기 |
| `q` | 종료 |

## 마우스

| 조작 | 동작 |
|------|------|
| 클릭 | 카드 선택 |
| 더블클릭 | 상세로 포커스 |
| 휠 | 그 칸을 위아래로 굴림 |
| 칸 머리 클릭 | 칸 접기·펼치기 |
| 드래그 앤 드롭 | 다른 칸으로 옮겨 상태 변경 |

터미널의 드래그로 글자를 선택하고 싶을 때는 `m` 으로 마우스를 끄십시오.

## 화면 폭에 따른 모드

pane 폭에 따라 배치가 바뀝니다.

| 폭 | 모드 |
|----|------|
| 140열 이상 | 보드 + 오른쪽 상세 패널 |
| 90 ~ 139열 | 보드만 |
| 90열 미만 | 목록 (한 줄에 한 건) |

폭이 모자라면 칸을 좁히지 않고 보이는 칸 수를 줄입니다. 카드 제목이 몇 글자 만에 잘려 읽을 수 없게 되는 편보다 낫기 때문입니다.

**목록 모드에서는 드래그로 상태를 바꿀 수 없습니다.** 화면에 칸 구분이 없어 어디에 떨어뜨릴지 알 수 없기 때문이며, 대신 `Space` 나 `H`/`L` 을 쓰십시오.

## 문제 해결

### 종료 후 터미널에서 마우스가 이상합니다

클릭이나 드래그 선택이 먹지 않으면 마우스 보고 모드가 켜진 채로 남은 것입니다. 다음을 실행하면 돌아옵니다.

```bash
printf '\033[?1006l\033[?1002l\033[?1000l'
```

플러그인은 종료·`SIGINT`·`SIGTERM` 모두에서 이 모드를 끄지만, 프로세스가 강제로 죽으면 정리가 돌지 못합니다.

### 화면이 실제 pane 보다 좁게 그려집니다

**Herdr 가 플러그인 pane 의 PTY 에 실제보다 작은 크기를 주는 문제가 알려져 있습니다.** 214열짜리 pane 인데 프로세스는 50열로 알고 있는 식이며, 이 경우 목록 모드로 떨어져 카드가 한 줄씩만 나옵니다. 크기가 바뀌어도 `resize` 이벤트가 오지 않아 앱이 처음 값에 갇힙니다.

플러그인은 이를 우회합니다. `HERDR_PANE_ID` 환경변수가 있으면 기동할 때 `herdr pane layout` 으로 실제 pane 크기를 직접 물어보고, 그 값이 `process.stdout` 보다 확연히 넓을 때만 씁니다. 따라서 대개는 저절로 맞습니다.

그래도 좁게 나온다면 다음으로 두 값을 비교해 보십시오.

```bash
herdr pane layout --pane <pane-id>
```

`rect` 의 크기와 화면에 그려진 폭이 크게 다르면 알려 주십시오.

### 마우스가 전혀 동작하지 않습니다

Herdr 설정에서 pane 앱이 마우스를 요청했을 때 넘겨주도록 되어 있는지 확인하십시오(`mouse_capture` 관련 설정). lazygit 이나 btop 에서 마우스가 되는지 보면 빠르게 가릅니다.

### API Key 가 올바르지 않다고 나옵니다

키가 만료되었거나 다른 서버의 키일 수 있습니다. 설정 파일을 지우고 다시 열면 최초 설정 화면이 뜹니다.

```bash
herdr plugin config-dir herdr-kanban   # 경로 확인 후 그 안의 config.json 삭제
```

## 개발

```bash
npm test           # 테스트
npm run coverage   # 커버리지
npm run build      # dist/cli.js 로 번들
```

`src/layout.js` 가 화면 좌표의 단일 출처입니다. 그리기와 마우스 판정이 같은 표를 보므로, 좌표 계산을 고칠 때는 `test/layout.test.js` 의 "영역이 서로 겹치지 않는다" 와 `test/ui-board.test.jsx` 의 "layout 이 말한 행에 그대로 그려진다" 를 반드시 통과시켜야 합니다.
